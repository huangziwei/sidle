                    Library

                    Location —

                    Move library

                    Move your library (books + database) into a new, empty folder. sidle verifies the copy, removes the old location, and restarts — nothing is left behind but a tiny pointer file in the app's support folder.

                    Use a library elsewhere

                    Point sidle at a library that already exists in another folder — one you moved by hand, or on an external drive. Nothing is copied. sidle restarts afterward.

                    Back up & restore

                    A backup is one .sidlebak file holding your whole library: every book and cover, and everything sidle keeps beside them — metadata, highlights, handwriting, your reading log, and the Kindle screenshots and logs under Misc. Restore replaces the current library and restarts; it asks first whether to delete the library it replaces or set it aside as an undo. Merge folds another library’s books and notebooks into this one — additive, nothing is removed, and no restart.
